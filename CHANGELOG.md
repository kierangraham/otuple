# Changelog

All notable changes to this project are documented in this file.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and the project uses [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-10-17

### Added

- Omarchy bar widget and shared service for the Tuple Linux CLI, installable with `omarchy plugin add`.
- Panel with searchable contacts, presence, and a Favorites tab.
- Calls to contacts, joining a pasted Tuple call link, and starting a call from your own link.
- Mute, Unmute, Share, Stop share, and Leave buttons.
- Tuple preferences for starting calls muted and the screen annotation overlay.
- Sign-in with an authorization code, and Go online / Go offline.
- Keyboard shortcuts for search, refresh, and preferences.
- Demo mode with sample contacts that never runs Tuple.
- Optional `otuple` launcher, icons, and desktop entry, with an Arch PKGBUILD.
